Ecological niche models (ENMs) were simulated based on the distribution layer of Rhinopithecus bieti (Zhao, 2019) and historical occurrence data. Five environmental variables with pairwise correlations of |r| < 0.7 were selected. Models were run in MaxEnt using 75% of the data for training with 1,000 bootstrap replicates, a minimum training presence logistic threshold, and all other parameters set to default values.
